# 文档同步与不可逆决策必须显式确认

## 背景

v1.2 已经有 PRD/INVARIANTS/MODULES 和决策董事会，但任务可以绕过文档更新直接 done；不可逆决策也可以只写“同意”。工作流评审要求文档同步和不可逆选择都留下明确证据。

## 决策

- Task 增加 `docsSynced: boolean`；项目绑定任一知识文档时，done 前必须为 true，否则 `docs_sync_required`。
- 勾选只表示“执行者/验收者确认文档已同步”，Studio 不自动改写文档，也不校验文件内容。
- Decision 增加 `reversible: boolean`，默认 true；提出决策时可标记不可逆。
- 不可逆决策批准时必须填写结论/理由，否则 `decision_reason_required`；拒绝不强制理由（但 UI 仍建议填）。
- 董事会显示“不可逆”标记；Task Room 显示文档同步勾选。
- schema v12 迁移：老任务 docsSynced=false，老决策 reversible=true。

## 考虑过的选项

1. **自动检查 PRD/ADR 的 git diff**：实现复杂，且“文档是否同步”是语义判断，不是文件存在。拒绝。
2. **不勾选就不允许 done**（选中）：最简单、可审计，但可能被形式化勾选。接受这个风险。
3. **不可逆决策只记录标记**：无法阻止“只点同意”；因此加理由门禁（选中）。

## 后果

- 文档门禁是人工确认，不是内容校验；勾选可能流于形式，后续可加 diff/摘要证据。
- 不可逆决策批准多一个输入步骤，但能留下理由。
- 已有 done 任务不会被追溯要求；只影响新 transition。
- 还没有自动生成 ADR 草稿；v1.4 再做。
