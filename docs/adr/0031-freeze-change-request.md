# 0031 冻结变更单

## 状态

已接受（v3.10.0）。

## 背景

PRD/架构冻结后，修改只能创建新版本，但缺少一条可审计的“为什么要改、影响什么、Owner 是否接受”的记录。直接建 v2 会让变更原因散落在聊天或提交信息里。

## 决策

1. `FreezeChangeRequest` 关联一个已冻结版本，记录：
   - 标题；
   - 变更原因；
   - 影响范围；
   - 状态 `pending | accepted | rejected`；
   - 创建/决定时间。
2. 只有 Owner 可以接受/拒绝；Pending 可改，已决定不可改。
3. 变更单不自动创建新冻结版本，也不自动修改 PRD/架构文件。
4. 接受变更单只表示“这个修改方向被批准”；实际修改仍要更新文档并创建新冻结版本。
5. schema 32 → 33；旧数据补 `freezeChangeRequests: []`。

## 影响

- 项目页冻结面板新增变更单表单和接受/拒绝按钮。
- 变更单不会解除 `freeze_drift`；漂移仍必须通过新版本解决。
- 变更单不是 Decision，不进入决策台。

## 非目标

- 不做多级审批。
- 不自动生成新版本。
- 不做变更内容 diff。
