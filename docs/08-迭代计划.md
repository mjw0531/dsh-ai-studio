- 不把 Studio 改成 SQLite；保持纯文本状态和可迁移性。

- 不在 PRD 阶段再加一套重型流程；只加冻结判据、领域模型和决策记录。
- 不在 CI 里自动发布；发布仍由人确认。

### 2.8 建议的功能冻结

完成 B1/B2（安全、评审证据、CI、首次体验）后，建议打一个 `v3.5.x` 稳定 tag，暂停新增功能，用 Studio 完成一个真实垂直切片（一个角色 + 一个能力 + 一次 核心 验证），验证：

- 13 个人工触点是否必要；
- 300 秒超时在真实任务上是否误判；
- 阶段/Demo 门禁对“手感/可玩性”是否有效。

这一步是产品验证，不是代码任务；结果再决定 B3/B4 的优先级。
